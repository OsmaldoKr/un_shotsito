# 🦝 UnShotsito

**UnShotsito** es una aplicación móvil desarrollada con **Flutter** que transforma cualquier reunión en una experiencia divertida mediante retos, castigos y desafíos aleatorios para jugar con amigos.

La aplicación ofrece diferentes categorías de juego, retos especiales y una interfaz moderna acompañada por la mascota oficial de UnShotsito: un mapache caricaturesco que guía a los jugadores durante toda la experiencia.

---

# ✨ Características

- 🎮 Registro de jugadores.
- 🃏 Retos aleatorios.
- ⭐ Retos especiales.
- 🍺 Castigos.
- 🎨 Interfaz moderna y responsive.
- 🦝 Mascota personalizada para cada categoría.
- 📱 Optimizada para dispositivos Android.
- ⚡ Desarrollada completamente en Flutter.

---

# 🎲 Categorías disponibles

Actualmente UnShotsito cuenta con las siguientes categorías:

- 🥂 Shots Ligeros
- 🌶️ Shots Picantes
- 🌙 Shots Nocturnos
- ❤️ Shots Calientes
- 💑 Shots en Pareja
- 🍻 Shots de Bar
- 🤫 Shots para Confesar

Cada categoría posee su propia identidad visual, retos exclusivos y una ilustración diferente del mapache.

---

# 🚀 Cómo jugar

1. Agrega los nombres de todos los participantes.
2. Selecciona la categoría de juego.
3. Lee el reto que aparece en pantalla.
4. Decide si el jugador cumplió o no el reto.
5. Si no lo cumple... ¡recibirá un castigo!
6. Continúen hasta que todos hayan participado.

Durante la partida pueden aparecer **Retos Especiales**, los cuales permanecen activos durante varios turnos y añaden un nivel extra de diversión.

# 📱 Instalación

Clona el repositorio:

```bash
git clone https://github.com/FratresPixel/un_shotsito.git
```

Ingresa al proyecto:

```bash
cd un_shotsito
```

Instala las dependencias:

```bash
flutter pub get
```

Ejecuta la aplicación:

```bash
flutter run
```

---

# 📦 Compilar APK

```bash
flutter build apk --release
```

---

# 📦 Compilar Android App Bundle

```bash
flutter build appbundle --release
```

# ⚠️ Consumo responsable

UnShotsito está diseñada exclusivamente para personas mayores de edad.

El objetivo de la aplicación es ofrecer entretenimiento durante reuniones sociales. Se recomienda disfrutar del juego con responsabilidad, respetar los límites personales de cada participante y nunca conducir bajo los efectos del alcohol.
